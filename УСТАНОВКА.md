# Установка и первый запуск

## Самый простой способ

Скинь архив и свой план (SVG, PDF или картинку с сайта ЖК) в Claude Code и напиши:

> Поставь этот скилл по УСТАНОВКА.md и разбери мой план

Дальше Claude сам распакует, поставит зависимости и спросит, чего не хватает: город, где север, высоту потолка.

## Для агента (Claude Code, Codex и другие)

Если пользователь прислал этот архив или ссылку на репозиторий, сделай так:

1. **Распакуй** архив в отдельную папку `claude-plan-check` рядом с текущим проектом пользователя (или `git clone https://github.com/AIsoidet/claude-plan-check`). Не распаковывай поверх чужих файлов.
2. **Проверь окружение:** `node -v` (нужен 20+), есть ли Chrome или Edge (для планшета и карточек). Чего-то нет, скажи пользователю, что именно поставить, и не продолжай установку.
3. В папке скилла выполни `npm install` (около минуты, ставится один пакет `@resvg/resvg-js`).
4. **Проверь пример:** `npm run all`. Должны появиться `out/01-axo.png` … `out/07-board.png`. Открой `out/07-board.png` и убедись, что он не пустой.
5. **Свой план.** Если пользователь дал файл плана, перенеси файлы примера из `src/` в `src/example/`, а `plan.json`, `out/checks.json` и `out/routes.json` переименуй в `*.example.json`. Потом скопируй план пользователя в `src/`. Если плана нет, спроси его и остановись.
6. **Работай из папки скилла:** прочитай `CLAUDE.md` целиком (правила и уровни утверждений) и выполни команды по порядку: `/zones` → `/fit` → `/flow` → `/sun` → `/bubble` → `/axo` → `/board`. Если slash-команды недоступны (папка открыта не как проект), открой `.claude/commands/<имя>.md` и выполни текст команды сам.
7. **Перед первым чертежом** спроси у пользователя то, чего нет на плане: город (широта), где север, высоту потолка. Ничего не выдумывай, допущения подписывай «принято».
8. Скрипты в `tools/` написаны под план из примера (координаты помещений в `make_plan.py`, точки маршрутов в `flow.mjs`). Для нового плана перепиши их под его геометрию, это ожидаемая часть работы.
9. **Масштаб** считай по площадям двух помещений, замкнутых стенами и без пилонов. Расхождение больше 2% значит, что контур выбран неверно. Пройди все слои плана: пилоны прячутся в «Несущие_колонны» и «Элементы_узлов».
10. **Перед тем как показать результат**, открой каждый PNG в полный размер: ничего не обрезано, подписи не наезжают друг на друга, цифры совпадают с `out/checks.json`.
11. **В конце** покажи пользователю `out/07-board.png` и список вопросов застройщику из `out/checks.json`. Ничего не публикуй и не отправляй без его просьбы.

## Вручную

Нужны: [Claude Code](https://claude.com/claude-code), Node.js 20 или новее, Chrome (для планшета и карточек).

1. Распакуй архив или склонируй репозиторий:
   ```bash
   git clone https://github.com/AIsoidet/claude-plan-check
   cd claude-plan-check
   ```
2. Поставь зависимости, это около минуты:
   ```bash
   npm install
   ```
3. Проверь, что пример собирается: `npm run all`. Листы появятся в `out/`.
4. Свой план: положи файл в `src/` (лучше векторный SVG или PDF с сайта ЖК; картинка тоже подойдёт, но точность ниже, тогда иди по `raster/README.md`) и удали `plan.json`.
5. Открой папку в Claude Code (`claude` в терминале) и набери `/zones`. Claude прочитает план, спросит город, где север и высоту потолка, посчитает масштаб по площадям и сверит площади с подписями. Если что-то не сходится, он остановится и скажет, где.
6. Дальше по очереди: `/fit`, `/flow`, `/sun`, `/bubble`, `/axo`, `/board`. Всё складывается в `out/`.

Команды лежат в `.claude/commands/`, правила в `CLAUDE.md`. Их можно скопировать в любой свой проект и править: пороги, цвета, набор листов.

Это разбор чертежа, строительную экспертизу он не заменяет. Нормы и практика подписаны на листах.
